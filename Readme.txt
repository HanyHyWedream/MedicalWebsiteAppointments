================================================
MediCare - Installation Guide
================================================

REQUIREMENTS:
------------
- MySQL Server 8.0 installed and running

FIRST TIME SETUP (Run Once)
----------------------------
1. Open the folder you received
2. Double-click "setup.bat"
3. Set a password when prompted 
4. Wait for "Database imported successfully!" message

LAUNCHING THE APP 
--------------------------------
1. Make sure MySQL is running
2. Double-click "Start MediCare.bat"
3. Wait a few seconds for the server to start
4. Your browser will open automatically at http://127.0.0.1:8000
